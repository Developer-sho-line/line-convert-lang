# line-convert-lang

# 🌏 Dialect Translator Bot

標準語をさまざまな方言や独特な話し方へ変換する Bot です。

LINE Bot や API と組み合わせることで、入力した文章を指定した話し方へ変換できます。

## 対応言語

- #猛虎弁
- #関西弁
- #英語
- #土佐弁
- #博多弁
- #津軽弁
- #うちなーぐち
- #古典
- #地獄のミサワ

---

# 変換例

| 標準語 | 変換後 | 総評 |
|--------|--------|------|
| おはよう！今日はいい天気だね。 | おはようや！今日はええ天気やな。 | 自然な関西弁。日常会話向け。 |
| おはよう！今日はいい天気だね。 | おはようやで！今日はええ天気やんけ！ | 猛虎ファン風の勢いある話し方。 |
| おはよう！今日はいい天気だね。 | Mornin', mate! Bonny day, innit? | 標準英語ではなく、イギリス・スコットランド系の方言や口語表現になる場合があります。 |
| おはよう！今日はいい天気だね。 | おはようぜよ！今日はこじゃんとえい天気やき。 | 坂本龍馬のような土佐弁の雰囲気。 |
| おはよう！今日はよか天気ばい！ | おはよう！今日はよか天気ばい！ | 博多弁らしい柔らかな語尾が特徴。 |
| おはよう！今日はいい天気だね。 | おはよう。今日はめぇ天気だな。 | 津軽弁は地域差が大きく、難易度も高め。 |
| おはよう！今日はいい天気だね。 | はいたい！今日はいっぺーいい天気さー。 | 沖縄（うちなーぐち）の表現を交えた話し方。 |
| おはよう！今日はいい天気だね。 | おはやう。今日は、いとよき天気なり。 | 古典日本語風の表現。 |
| おはよう！今日はいい天気だね。 | 今日はいい天気……つまり俺が本気を出す日ってことか。 | 『地獄のミサワ』風の独特な言い回しで、ネタ要素が強い。 |

---

# 特徴

- 標準語から各方言へ自然な変換
- 地域特有の語彙や語尾を再現
- 英語は単なる翻訳ではなく、イギリス英語・スコットランド英語など、方言色の強い表現になる場合があります
- ネタ系（地獄のミサワ）にも対応

---

# 使用例

```text
入力
#関西弁 @user 
今日は疲れたから帰るよ。

出力
今日は疲れたさかい帰るわ。
```

```text
入力
#古典 @user 
なんと美しいことだ。

出力
あはれ、いとをかし。
```

```text
入力
#英語 @user 
今日は疲れたから帰るよ。

出力
I'm knackered today, so I'm headin' home, mate.
```

---

# 注意事項

- 方言には地域差・世代差があります。
- 英語はアメリカ英語ではなく、イギリス・スコットランドなどの口語・方言表現になることがあります。
- 地獄のミサワは雰囲気を再現したジョーク変換です。
- 出力は AI による生成のため、必ずしも地域で一般的な表現とは限りません。
